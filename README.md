# Q4 绩效任务桌面看板

这是一个可导入 Wallpaper Engine 的 Web 壁纸：它将 2026 Q4 试用期目标固定展示在桌面，并支持勾选任务、查看里程碑、记录每日完成事项和阻塞点。

## 已包含的内容

- 5 个绩效维度、11 个主任务及其权重、产出与时间范围。
- 6 个关键里程碑：10 月 21 日、10 月 22 日、12 月 11 日、12 月 31 日等。
- 点击任务切换“已完成”状态，顶部自动汇总进度。
- 每日记录按 PDCA 组织：计划/假设、行动与产出、学习与证据、导师同事反馈、调整决策与下一步；历史记录保留最近 7 天。
- 点击“导出周复盘”可生成本周 Markdown 文件，内含每日 PDCA 素材、已勾选任务、阻塞和下周计划模板。
- 可保存滴答清单任务或清单链接，并从记录面板直接跳转。

所有勾选和日志当前都存储在浏览器或 Wallpaper Engine 的本地存储中。跨设备同步功能尚未上线；上线前不会自动上传既有日记录、附件或电脑文件。

## 数据与公开边界

- GitHub Pages 与仓库源码是公开的，只包含固定的 Q4 任务结构和程序代码。
- 日记录、周复盘导出 JSON、附件原文、服务端密钥与账号令牌不得提交到本仓库。
- 后续同步将使用个人登录后的私有数据空间；发生多设备冲突时始终由用户选择保留本机、采用云端或合并。
- 在同步功能完成前，请定期导出 Markdown 周复盘，并保留本地副本。

## 导入桌面

1. 打开 Wallpaper Engine 编辑器，创建 **Web 壁纸**。
2. 选择本目录中的 `index.html`，或将整个 `q4-performance-wallpaper` 文件夹拖入编辑器。
3. 在属性面板按需替换“背景图片”，然后发布或应用。
4. 在桌面壁纸上点击右侧任务卡片，可勾选任务；点击“填写 / 查看”记录 PDCA 素材；周末点击“导出周复盘”下载 Markdown 初稿。

普通浏览器预览：在本目录运行 `node .\\tools\\static-server.mjs`，再打开 `http://127.0.0.1:5173/`。

## 滴答清单

当前版本采用“链接跳转 + 本地留痕”方式：在每日记录中粘贴某个滴答清单任务或清单的链接即可。未直接读写 TickTick，因为这需要单独的授权/API 接入；若后续确定允许使用其开放 API 或自动化方案，可在不改变看板结构的前提下增加双向同步。

## 维护提示

任务结构与里程碑定义在 `app.js` 顶部的 `goals`、`milestones` 中。只有绩效目标实际变化时再修改它们，避免把日常推进记录混入任务定义。
